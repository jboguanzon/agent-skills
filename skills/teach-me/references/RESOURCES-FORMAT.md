# RESOURCES.md Format

Optional until the first verified source. Curated, not exhaustive — better five sharp sources than thirty mediocre ones.

````md
# <Topic> Resources

## Knowledge
- [Title (Publisher)](url)
  What it covers. Use for: <when to reach for it>.
- [Title](url)
  What it covers. Use for: <...>.

## Wisdom (Communities)   # optional; user preference governs
- [r/<subreddit>](url)
  High-signal community. Use for: <judgement questions, real-world testing>.
````

Rules:

- High-trust only: primary sources, official docs, recognized experts. Marketing dressed as education stays out.
- Annotate every entry; a bare link is useless in three months.
- Group by Knowledge / Wisdom. Fine for a resource to appear in only one group.
- Surface gaps: if the mission needs an area with no good source, write a `## Gaps` section. This drives future research.
- Prune ruthlessly: a source that turned out wrong, shallow, or off-mission gets removed, not buried.
