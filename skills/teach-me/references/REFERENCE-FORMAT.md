# Reference Format (reference/<slug>.md)

What the user actually returns to. One file per cheat-sheet/glossary/algorithm, terse and scannable: tables, syntax, pseudocode, key terms with one-line definitions, links back to the lessons that introduced them.

````md
# <Topic> — <sheet name>

| Term / syntax | Meaning |
|---|---|
| ... | ... |

<one-line links to originating lessons>
````

Rules:

- Terse and scannable over prose; the user is reaching for this mid-task, not reading for pleasure.
- Glossaries: once the first glossary exists for a topic, every lesson must use its terms — don't introduce competing definitions.
- Each sheet links back to the lessons that introduced the material.
