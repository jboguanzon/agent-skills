# BASELINE.md Format

Written once, after the first-session probe. Never re-probed in later sessions unless the user says their level changed.

````md
# Baseline: <Topic>

Probed <date>. Current level per strand; the edge is bracketed (floor = reliably known, ceiling = where it runs out).

## <strand 1>
- Floor: <what they reliably know — with evidence: "answered X correctly", "stated they use Y daily">
- Ceiling: <where it runs out — with evidence>
- Misconceptions found: <none, or list each with its extent — these seed learning records>

## <strand 2>
...
````

Known strands (floor + ceiling found) can be **skipped** in the plan: teaching starts at the edge, not below it.
