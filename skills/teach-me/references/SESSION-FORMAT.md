# Session Handoff Format (SESSION.md)

The handoff. Rewritten at the end of every session; read at the start of the next. Keeps the finer-grained position that PLAN.md node statuses don't carry.

````md
# Session handoff: <Topic>

Last session: <date>

## Position
- Plan node: <# / name — or "between lessons NNNN and NNNN">
- Mid-lesson: <where exactly, if a lesson file is unfinished: which concept was being established>
- Warm-up gate due: <yes / no — no if a warm-up ran at session start>

## Next up
<The concrete next action: teach node N, finish lesson NNNN, write reference sheet for X, ...>

## Open threads
- <anything the user asked to follow up on, open questions, ideas to test>
````

A `continue <topic>` session with no `SESSION.md` (or a stale-looking one) means: compute the next lesson from mission + learning records and propose it before teaching. Confirm `SESSION.md` is fresh before overwriting it.
